# GastroSoft - Sistema POS para Gastrobares

GastroSoft es una solución web transaccional diseñada para optimizar y agilizar la operación integral de restaurantes y gastrobares.
Articula la gestión de salón en vivo, captura móvil de comandas, monitoreo de cocina (KDS), liquidación de cuentas en caja y control de inventario.

---

## Características Principales

* **Mapa Interactivo de Salón:** Visualización en tiempo real del estado de mesas mediante código semafórico (Libre, Ocupada, Precuenta).
* **Toma de Comandas Móvil:** Registro ágil de pedidos vinculados a mesa con especificaciones y notas para cocina.
* **Monitor KDS (Kitchen Display System):** Pantalla en tiempo real para cocineros y bartenders con control de estados y tiempos de preparación.
* **Módulo de Caja y Facturación:** Gestión de precuenta, cobro con múltiples medios de pago (efectivo, tarjeta, transferencia) y arqueo de caja diario.
* **Control de Inventario y Carta:** Gestión de productos, categorías y alertas automáticas por bajo stock.
